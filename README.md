# You Matter

A mobile-first wellbeing reflection and mental-health awareness website created for ENLIT, The Literary Club of Easwari Engineering College.

## Deploy on Vercel

Import this repository into Vercel. Keep the framework preset as **Other** and leave the build command empty. The site is a static HTML project and deploys directly from the repository root.

The reflection is not a diagnosis, and responses are processed only in the visitor's browser.
